Privacy policy

Last updated: 25 November 2026

BEAN STUDIO is a private tool used only by its owner to manage the owner's own YouTube channels.

What data the tool accesses

  • Through Google sign-in (OAuth) and the YouTube Data API / YouTube Analytics API: the owner's channel information, video list, video metadata, captions, playlists, comments and channel analytics.

How the data is used

  • Only to upload and edit the owner's own videos (titles, descriptions, tags, thumbnails, subtitles, playlists, scheduling), post the owner's own comments, and show the owner reports about the owner's channels.
  • Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Locally stored tokens are deleted when access is no longer needed.
